# আমার ব্যবসা — অফলাইনে চালানোর প্যাকেজ

এই ফোল্ডারটি নিজের একটি ফ্রি ওয়েবসাইটে রাখলে অ্যাপটি ফোনে ইনস্টল হয় এবং **ইন্টারনেট ছাড়াই খোলে**।
(Blogger-এ সার্ভিস ওয়ার্কার চলে না, তাই Blogger-এ অ্যাপ খোলা অবস্থায় নেট গেলে চলবে, কিন্তু নেট ছাড়া আবার খুললে খুলবে না।)

## ফাইল
- `index.html` — অ্যাপ নিজে
- `sw.js` — অফলাইনে অ্যাপ খোলার ব্যবস্থা
- `manifest.json`, `icon-*.png` — ফোনে ইনস্টলের জন্য
- `firebase.json` — Firebase Hosting ব্যবহার করলে লাগবে

## সবচেয়ে সহজ উপায়: GitHub Pages (শুধু ব্রাউজার লাগে)
1. github.com-এ বিনামূল্যে অ্যাকাউন্ট খুলুন → **New repository** → নাম দিন `amar-bebosha` → **Public** → Create।
2. **Add file → Upload files** চাপুন, এই ফোল্ডারের সব ফাইল (zip খুলে) টেনে এনে **Commit** করুন।
3. **Settings → Pages → Branch: main / (root) → Save**।
4. ১–২ মিনিট পর `https://আপনার-নাম.github.io/amar-bebosha/` লিংক পাবেন।

(বিকল্প: Netlify Drop — app.netlify.com/drop-এ ফোল্ডারটি টেনে ফেললেই লিংক পাওয়া যায়।)

## ⚠️ বাধ্যতামূলক: Firebase-এ ডোমেইন অনুমোদন
Firebase Console → **Authentication → Settings → Authorized domains → Add domain** →
`আপনার-নাম.github.io` (শুধু ডোমেইন, পুরো লিংক নয়) যোগ করুন। না করলে লগইন হবে না।

## ফোনে ইনস্টল ও অফলাইন চালু করা
1. ফোনের Chrome-এ লিংকটি **ইন্টারনেট থাকা অবস্থায়** খুলে লগইন করুন।
2. এক-দুইবার পেজ রিলোড করুন (যেন ফাইলগুলো ফোনে জমা হয়)।
3. Chrome মেনু ⋮ → **Add to Home screen / Install app**।
4. এরপর হোম স্ক্রিনের আইকন থেকে খুলুন — নেট ছাড়াও খুলবে।

## অফলাইনে যা হয়
- খাতা, ক্যাশবক্স, স্টক — সব লেনদেন ফোনে সংরক্ষিত হয়।
- উপরে সতর্কতা দেখায়: **"ইন্টারনেট সংযোগ দিন — হিসাব ব্যাকআপ হয়নি"**।
- ইন্টারনেট এলে নিজে থেকে সার্ভারে সিঙ্ক হয়, তখন "✅ সব হিসাব ব্যাকআপ হয়েছে" দেখায়।

## সীমাবদ্ধতা
- প্রথমবার লগইন/রেজিস্টার, পেমেন্ট জমা ও অ্যাডমিন কাজে ইন্টারনেট লাগে।
- সিঙ্ক হওয়ার আগে ব্রাউজারের ডেটা মুছলে বা অ্যাপ আনইনস্টল করলে ওই লেনদেন হারাবে — সতর্কতা না মেলা পর্যন্ত এমন করবেন না।
- Blogger লিংক ও নতুন লিংকের ফোনে-জমা ডেটা আলাদা, কিন্তু অনলাইন ডেটা (একই অ্যাকাউন্ট) একই।
